# Hedroom downloads

Signed and notarized builds of [Hedroom](https://hedroomapp.com), the Mac utility that finds what is slowing your Mac and proves each fix with a measured receipt.

- Download the latest build from [Releases](https://github.com/nafiulhasanbd/hedroom-releases/releases/latest).
- Requires macOS 15 or later on an Apple Silicon Mac.
- Hedroom updates itself through Sparkle. The update feed is `https://hedroomapp.com/appcast.xml`.
- Monitoring is free. Fixes need Hedroom Pro. See [hedroomapp.com/pricing](https://hedroomapp.com/pricing).

This repository holds release files only, not source code. Questions: see [hedroomapp.com/support](https://hedroomapp.com/support).
